\section*{PROJECTS}
\textbf{Astral  ---  Cross-Platform BLE Mesh SDK (Rust core → iOS + Android)}
\vspace{1pt}
\begin{itemize}[leftmargin=11pt,itemsep=0pt,topsep=1pt,parsep=0pt]
\item Built one Rust engine (astral-core: cryptography, MTU slicing, spray-and-wait routing) and bridged it to both mobile stacks with Mozilla UniFFI  ---  Swift XCFramework for iOS, Kotlin via JNI for Android  ---  so the mesh protocol is byte-identical on every device (10,700+ LOC total).
\item Solved the iOS↔Android BLE interop problems platform by platform: manual CCCD descriptor (0x2902) writes on Android Centrals to correctly subscribe to iOS Peripheral ACKs (the "merchant did not respond" bug), sequential onCharacteristicWrite queues replacing racy timer-based writes, and dynamic MTU negotiation to 512 B with fragmentation for 200–500 B payloads.
\item Implemented hardware-backed identity on both platforms: iOS Secure Enclave and Android Hardware Keystore P-256 keypairs, with ChaCha20-Poly1305 AEAD parity between Apple CryptoKit and java.security down to the byte.
\item Shipped demo apps on both platforms (Android wallet + QR scanner screens, iOS app) plus a Next.js/Supabase reconciliation backend for when devices reconnect.
\item Tech: Rust, Swift, Kotlin, UniFFI, BLE GATT, Noise Protocol  ---  github.com/Aryan-Protein-Vala/Astral-Offline \,·\, github.com/Aryan-Protein-Vala/Astral-Network
